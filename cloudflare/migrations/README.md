# CommunityのDB初期化

Community専用の新しいSQLiteまたはD1へ、番号順に適用するSQLです。SaaSの既存DBを初期化先に指定しないでください。新規配布のため、商用のSCIM・管理者監査・スナップショットのテーブルは含みません。今後の変更には新しい番号のマイグレーションを追加します。

- 0001: 利用者、Freeワークスペース、所属とrevision。
- 0003: 単一のFreeプロファイル、個人設定、資料とチャンク。
- 0004/0005: 工事とタスクの個別履歴。
- 0006: 明示的に有効化するNotion同期の暗号化設定・対応表・再開状態。
- 0007: 台帳と点検履歴の行単位保存。旧形式JSONの配列順序と履歴を維持。

番号0002はこの配布では使用しません。セルフホストのサーバーは適用済み番号を記録し、再起動時に再適用しません。資料はmap_file_chunksへ保存します。工事と作業の個別履歴が参照する資料は削除から保護し、台帳更新と同じトランザクションで保存します。

[セルフホストの運用](../../docs/self-hosting.md)と[構成](../../docs/architecture.md)を参照してください。
