# Communityの機能

Freeの機能を一つの共有ワークスペースで利用します。図面3枚、設備100台、資料10MB。台帳全体750KB、添付は各5MB・一度に合計5MBまでです。

- 敷地図・棟内図・ASCII DXF・階層移動・レイヤーセット。
- 工事範囲・期間・状態、設備の位置や属性のロック、分類とカスタム属性。
- 写真・PDF・点検用紙、設備の点検履歴、CSV/JSONの検証と取り込み。
- 案件、タスク、担当者、先行作業と子作業、完了条件、点検計画、引き継ぎ。
- 工事・タスクごとの変更履歴。履歴が参照する添付を削除から保護します。
- 左右パネル、密度、サイズ、ズーム連動、表示プリセット。テーマは端末の設定に追従。
- 同一ホストのREST API、OpenAPI、WebMCP。
- 明示的な設定で有効にするNotionの双方向同期。競合や削除は画面で確認。

含まない機能は、プラン変更・課金・有料デモ、独自アイコン、配色・テーマの手動指定・ブランド変更、世代バックアップ、管理者監査、SCIMです。該当APIの実装と公開経路を含めません。HTTP認証はサーバー全体を保護し、閲覧モードには設備・属性・タスクを返しません。
